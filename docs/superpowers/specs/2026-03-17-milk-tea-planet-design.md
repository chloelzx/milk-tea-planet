# 奶茶星球 (Milk Tea Planet) — 设计文档

## 产品定位

**一句话描述**：记录每一杯奶茶，收集属于你的治愈小星球。

**目标用户**：喜欢喝奶茶的年轻女性，追求可爱、治愈的体验。

**核心价值**：用正向、有趣的方式记录奶茶消费，而非制造卡路里焦虑。

## 核心体验循环

1. 用户在聊天框输入，如"今天喝了一杯伯牙绝弦"
2. DeepSeek AI 识别品牌和饮品，回复治愈文案 + 正向换算
3. 聊天流中弹出精美奶茶卡片（正面治愈、背面数据，支持翻转）
4. 星球上对应品牌元素亮起（首次）或杯数增长（重复）

## 页面结构

单页面，三个区域：

### 顶部 — 奶茶星球（约 1/4 页面）

- 可爱的星球插画，纯 CSS/SVG 绘制
- 5 个品牌各对应星球上的一个元素
- 未收集：灰色轮廓；已收集：彩色亮起
- 点击星球 → 展开图鉴面板（全屏 overlay）

### 中部 — 聊天流（页面主体）

- 用户消息 + AI 回复 + 奶茶卡片穿插
- 上下滚动

### 底部 — 输入框（固定）

- 简洁输入框，placeholder："今天喝了什么呀？"

## 奶茶卡片设计

### 正面（默认）

- 品牌视觉插画
- 饮品名称
- 正向换算（随机选取 2-3 个维度）：
  - "相当于 15 分钟午后阳光"
  - "相当于听 3 首喜欢的歌的快乐"
  - "足够让一朵小花开放"
  - "相当于撸猫 10 分钟的治愈力"
- 角落有"点击翻转看更多"小提示

### 背面（用户手动翻转）

- 卡路里数值
- 运动换算：散步 / 跑步 / 游泳对应时长

## 视觉风格

### 色调

- 主色：奶茶色（#F5E6D3）
- 辅色：淡棕（#C4A882）、浅粉（#F2D7D9）
- 背景：米白到淡奶茶色渐变
- 强调色：各品牌自有品牌色

### 画风

- 扁平插画风，圆角、柔和线条
- 简笔插画风格（手账贴纸感）
- 圆体字体
- 不用拟物、不堆阴影、不过度渐变

## 品牌视觉

| 品牌 | 星球元素 | 卡片主色 |
|---|---|---|
| 喜茶 | 一杯冒气泡的果茶 | 葡萄紫 |
| 霸王茶姬 | 一片茶叶 | 中国红 + 金 |
| 茶颜悦色 | 一把小团扇 | 中式粉棕 |
| 茉莉奶白 | 一朵茉莉花 | 白绿色系 |
| 蜜雪冰城 | 雪王 | 红白 + 柠檬黄 |

## 图鉴系统

### 图鉴面板

- 全屏 overlay，背景半透明模糊
- 5 个品牌格子排列
- 已收集：彩色亮起，品牌名 + 已喝杯数
- 未收集：灰色剪影 + "???"
- 点击已收集品牌 → 展开该品牌下的饮品列表

### 收集触发

- 首次记录某品牌 → 解锁，星球亮灯 + 庆祝动画（星星冒出）
- 重复记录 → 杯数 +1，无重复庆祝

## 技术方案

### 前端

- 单 HTML 文件 + CSS + JavaScript，无框架
- 数据存储：localStorage
- 卡片翻转：CSS 3D transform
- 星球 / 品牌元素：SVG 或 CSS 绘制（纯代码，无外部图片）
- 动画：CSS animation

### AI 接入

- DeepSeek API（兼容 OpenAI 格式）
- 前端直接调用（demo 级别）
- Prompt 预设：识别品牌和饮品 → 估算卡路里 → 生成治愈文案 + 正向换算 + 运动换算 → JSON 格式返回
- 前端解析 JSON 渲染卡片

## 初版范围

- 5 个品牌，每品牌预设热门饮品数据（AI 可识别更多）
- 聊天 + 卡片 + 星球 + 图鉴完整流程
- 纯前端部署，打开 HTML 即可使用
